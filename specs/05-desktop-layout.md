# Spec 05 — Desktop Layout (Design Only)

## Goal
Produce desktop layout screens for all existing app pages in Brilliant (Figma-like tool with MCP).
No code is written in this spec. Output is reviewed designs only.

## Scope
- Every existing screen gets a desktop variant
- Layout shift from mobile-first single-column to desktop multi-column where appropriate
- No feature changes — same functionality, different layout

## Priority Order (design first)
1. Dag-panel
2. Projekt (including new CTA from spec 08)
3. Konton
4. Snabb Pass (including bulk from spec 01)
5. Arbetsdagbok
6. Inställningar (settings page from spec 04)
7. All remaining screens

## Process
1. Open Brilliant via MCP
2. For each screen: create a desktop frame (1440×900 or 1280×800)
3. Redesign layout — wider content area, potential sidebar nav, card grids instead of stacked lists
4. When all screens are drafted: review session with user → adjustments → then and only then consider building

## Constraints
- Do not touch any code
- Do not deploy anything
- Output: Brilliant project with all screens, shared link delivered to user
