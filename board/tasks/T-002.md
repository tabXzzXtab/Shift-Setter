## Full page flow

### 1. Project selector (top)
- Dropdown showing all active projects for the bolag
- Required before proceeding
- Same pattern as existing project dropdowns in the app

### 2. Date calendar
- Multi-select calendar (same as existing Snabb Pass)
- Selected dates appear as orange chip pills below the calendar
- **Remove any future-date-only restriction** — allow past dates freely

### 3. Worker count selector
```
Hur många arbetare?
[ 1st ]  [ 2st ]  [ 3st ]  [ 4st ]  [ 5st ]
```
- Tapping a number pre-creates that many card slots per selected day
- Orange highlight on selected count
- Changing the count after cards are shown: prompt "Vill du nollställa korten?" before resetting

### 4. Card grid
Layout:
- Scroll **left/right** to move between selected days
- Scroll **up/down** to see all worker slots for that day
- Day label shown as sticky header above each column (e.g. "21 Nov")
- N cards per day column (N = selected worker count)

Each card contains:
```
[ Person ▼ ]              (dropdown — all active workers in bolag)
Från  [ 07:00 ]   Till  [ 16:00 ]   (editable, default 07:00–16:00)
[ 15 min ]  [ 30 min ]  [ 45 min ]  (break presets, orange on selected)
Arbetstid: 8:30              (gap = (Till - Från) - break, auto-calculated)
[ custom gap input ]         (optional — type hours like "8.5"; back-calculates break = (Till-Från) - typed gap)
```

Logic:
- On load: start=07:00, end=16:00, no break selected, no gap shown
- When user picks a break preset: gap updates immediately
- When user types in custom gap field: gap = typed value, break = (end - start) - gap (displayed as calculated break below the input)
- Changing start/end time: gap recalculates based on currently selected break or custom gap
- Person dropdown: searchable, shows all active workers; required before submit

### 5. Submit button
- Label: "Skapa skift" 
- Disabled until every card has a person selected
- On press: loop `create_snabb_pass` RPC for each filled card (N × M calls)
- Show progress indicator during creation
- On success: toast "X skift skapades" + navigate back to project/dag view
- On error: show which card failed, allow retry
