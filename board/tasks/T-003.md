# T-003 — Radera Projekt (Delete Project in Dropdown)

**Status:** PENDING  
**Priority:** MEDIUM  
**Assigned to:** worker

---

## Goal

Add a "Radera projekt" option to the project action menu. Admin-only. Requires confirmation warning before executing.

---

## Where it appears

When a user taps on a project (opens the project action dropdown/sheet), add a destructive option at the **bottom** of the menu:

```
[ Redigera projekt ]
[ ... other options ... ]
─────────────────────
[ Radera projekt ]     ← red text, destructive style
```

---

## Access control

- **Admin only**: hide this option entirely for `arbetssledare` role
- Use the existing role-check pattern in the codebase (check how other admin-only buttons are hidden)

---

## Confirmation dialog

When admin taps "Radera projekt":

```
Radera projekt?

"[Projektnamn]" och alla tillhörande skift kommer att raderas permanent. 
Detta går inte att ångra.

[ Avbryt ]    [ Radera ]
```

- "Avbryt" → dismiss, do nothing
- "Radera" → execute deletion, red/destructive button style
- Project name in quotes in the warning text

---

## Deletion logic

1. Check how projects are currently structured in the DB (look at the `projekt` table and any foreign keys)
2. Delete or cascade-delete associated records as needed
3. If cascade delete is risky, use a soft delete: add `deleted_at timestamptz` to `projekt` table if it doesn't already exist, set it on delete, and filter it out of all project queries
4. After deletion: navigate back to the project list, show toast "Projekt raderat"

**Prefer soft delete** if the table has associated shifts/tilldelningar — safer than hard delete.

---

## Migration (if soft delete needed)

```sql
ALTER TABLE projekt ADD COLUMN IF NOT EXISTS deleted_at timestamptz;
```

Run in Supabase SQL editor. Then edit `database.types.ts` BY HAND to add `deleted_at: string | null` to the projekt row type.
