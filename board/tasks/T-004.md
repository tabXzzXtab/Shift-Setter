# T-004 — Adress Autocomplete på Projekt

**Status:** DONE  
**Priority:** MEDIUM  
**Assigned to:** worker

---

## Goal

Replace the plain address text input on project creation/edit with an autocomplete field that suggests real Swedish addresses as the user types.

---

## Where it appears

- Project creation form (wherever the address field currently lives)
- Project edit form (same field)

---

## Behavior

1. User starts typing an address → dropdown appears with matching real addresses
2. Suggestions narrow with each keystroke
3. User taps a suggestion → field fills with the full formatted address
4. User can still type freely if they want a custom value (not forced to pick from list)

Example:
```
[ Storg█ ]
  ↓
  Storgatan 1, Stockholm
  Storgatan 14, Göteborg
  Storgatans väg 3, Malmö
```

---

## Implementation

### Option A — Google Places API (preferred if API key exists)
1. Check `.env.local` for `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` or similar
2. If key exists: use `@googlemaps/js-api-loader` or the Places Autocomplete widget
3. Restrict to Sweden: `componentRestrictions: { country: 'se' }`
4. Use `address` type in autocomplete

### Option B — Nominatim (free, no key needed)
If no Google Maps key:
1. Use OpenStreetMap Nominatim API: `https://nominatim.openstreetmap.org/search?q={input}&countrycodes=se&format=json&addressdetails=1`
2. Debounce requests (300ms)
3. Show results in a custom dropdown below the input
4. Rate limit: max 1 req/sec — debounce handles this

**Use Option B if no Google Maps key is found in env.**

---

## UI

- Dropdown appears below the input, same width
- Max 5 suggestions shown
- Highlighted on hover/focus
- Closes on outside click or Escape
- Loading spinner while fetching (subtle, inside input)
- If no results: show "Inga adresser hittades" and allow free text

Address is already stored as text in the projekt table. No DB changes.
